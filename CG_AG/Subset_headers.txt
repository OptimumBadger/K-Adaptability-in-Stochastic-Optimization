================================================================================
SUBSET FORMULATION OUTPUT FILE HEADERS
================================================================================

This document describes the headers for the three types of output files 
generated by Subset.jl (Subset Formulation Column Generation).

================================================================================
1. RESULTS FILE
================================================================================
Filename format: CG_SF_<instance>_K<K>_S<S>_<variance>_results.txt

Tab-separated columns (no header row written in file):

1.  Instance              - Instance name (e.g., "cap91.txt")
2.  nloc                  - Number of facilities
3.  ncust                 - Number of customers
4.  K                     - Number of candidate solutions
5.  S                     - Number of scenarios
6.  Iterations            - Total iterations performed
7.  TotalWorkUnits        - Total work units consumed
8.  TotalSolutionsAdded   - Total number of columns/solutions added
9.  Status                - LP termination status (OPTIMAL/FAILED)
10. Placeholder           - Fixed value 0.00 (reserved field)
11. MasterWorkUnits       - Work units for master problem
12. PricingWorkUnits      - Work units for pricing subproblems
13. UpdateWorkUnits       - Work units for master problem updates
14. FinalObjectiveLP      - Final objective value (Linear Relaxation)
15. FinalObjectiveIP      - Final objective value (Integer Solution) or "NaN"
16. Gap                   - Optimality gap percentage or NaN

Example data row:
cap91.txt	25	50	2	25	1	2.96	10	OPTIMAL	0.00	0.0	2.96	0.0	70140.64	NaN	NaN

================================================================================
2. ITERATIONS FILE
================================================================================
Filename format: CG_SF_<instance>_K<K>_S<S>_<variance>_iterations.txt

Tab-separated columns (no header row written in file):

1.  Iteration        - Iteration number
2.  MasterObjective  - Master problem objective value at this iteration

Example data rows:
1	70140.64
2	69500.23
3	69000.15

================================================================================
3. SUBPROBLEM COMPARISON FILE
================================================================================
Filename format: CG_SF_<instance>_K<K>_S<S>_<variance>_subproblem_comparison.txt

Tab-separated columns (no header row written in file):

1.  Instance           - Instance name (e.g., "cap91.txt")
2.  S                  - Number of scenarios
3.  K                  - Number of candidate solutions
4.  AvgType1WorkUnits  - Average work units for Type 1 pricing (if comparison was done)
5.  AvgType1Nodes      - Average B&B nodes for Type 1 pricing
6.  AvgType2WorkUnits  - Average work units for Type 2 pricing
7.  AvgType2Nodes      - Average B&B nodes for Type 2 pricing

Note: This file contains comparison metrics if both Type 1 and Type 2 pricing
were run in the first 10 iterations. Otherwise, all values are 0.000.

Example data row:
cap91.txt	25	2	25.31	7526.0	2.96	2974.0

================================================================================
NOTES
================================================================================

- All files are tab-separated (.tsv format)
- No header rows are written to the files (headers shown above are for reference)
- Files are overwritten on each run
- Instance name is hardcoded as "cap91" in Subset.jl
- Gap is calculated as: (IP - LP) / LP * 100

================================================================================
